# Results Directory

This directory stores experimental results from running the autonomous tank AI.

## Files

- `runs.csv` — Summary of all runs (one row per run)
- `summary.txt` — Aggregated statistics (generated by `npm run compare`)
- `v{N}_run{M}_{timestamp}.log` — Full stdout/stderr from each run

## CSV format

| Column | Description |
|--------|-------------|
| version | v26, v27, v28, v29, v30 |
| run | Run number (1, 2, 3, ...) |
| timestamp | ISO timestamp of run start |
| kills | Total enemies eliminated |
| deaths | Number of ticks spent dead |
| died_at_tick | Tick number when HP first hit 0 (empty if survived) |
| final_hp | HP at end of run |
| final_pos_x | Final X position |
| final_pos_y | Final Y position |
| log_file | Filename of the full log |

## How to generate results

```bash
# Run each version once
npm run run:all

# Run each version 3 times for statistical significance
node run_all.js 3

# View summary
npm run compare
```

## How to add a new version

1. Copy `play_tigertank30.js` to `play_tigertank31.js`
2. Modify the heuristics
3. Add the version to the `VERSIONS` array in `run_all.js`
4. Add an npm script in `package.json`: `"run:v31": "node play_tigertank31.js"`
5. Run: `npm run run:all`
6. Compare: `npm run compare`
